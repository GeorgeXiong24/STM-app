# STM — 智能记忆测试（Smart Testing of Memorization）

> 一款由 AI 驱动的单词记忆测试应用，配合**你自己的单词表**使用。

[English](README.md) · [中文](README_zh.md)

## STM 是什么？

STM 是一款桌面应用，用于测试你对一组单词的掌握程度。与固定的词典或选择题不同，STM 允许你导入自己的单词表，并用你自己的话来作答。

- 上传你自己的 `.xlsx` 或 `.numbers` 单词表。
- AI 会自动识别每个单词及其对应的中文释义，无论列表如何排版。
- 由于一个单词可能有多种含义，AI 会判断你的回答是否与正确含义相符，而不仅仅是逐字比对。
- 测试结束后会生成一份报告，列出你答错或放弃的单词，并可导出用于复习。

## 支持的语言

单词可以是以下任意一种语言：

中文 · 法语 · 德语 · 西班牙语 · 意大利语 · 葡萄牙语 · 日语 · 韩语

释义以**中文**显示并进行测试。

## 工作原理

1. **识别** — 当你上传表格时，STM 会让 DeepSeek AI 识别每个单词及其对应的中文释义，不受列名或排版的影响。
2. **判断** — 测试时你需要用中文输入释义。AI 会将你的回答与参考含义进行比较，并接受同义词、自然改写以及少量拼写错误。
3. **复习** — 答错的单词会在最后再测一次。

## 快速上手

1. 获取一个 DeepSeek API 密钥（以 `sk-` 开头）。
2. 从 [Releases](https://github.com/GeorgeXiong24/STM-app/releases) 页面下载最新版本。
3. 打开 STM，粘贴你的 API 密钥，然后点击 **OK**。
4. 选择单词所属的语言。
5. 将 `.xlsx` 或 `.numbers` 文件拖入窗口，或使用 **File → Open…**。
6. 检查识别出的单词，删除不需要的行。
7. 点击 **Go** 开始测试。
8. 对每个单词输入其中文释义，按 **Enter** 或点击 **OK**。
9. 测试结束后查看报告，并可导出答错的单词。

## 测试流程

- 每个单词有两次作答机会。
- 不会的单词可点击 **Give up** 跳过。
- 正确答案会自动填入。
- 答错的单词会在最后的复习环节再次出现。

## 导出结果

测试结束后，你可以将答错或放弃的单词导出为 `.xlsx` 或 `.numbers` 文件，并可选显示每个单词答错的次数。

## 注意事项

- 上传的文件仅临时存储，关闭 STM 后会被删除。
- 按 **Esc** 可返回上一界面。
- 在 macOS 上如遇到问题，请参阅 [Mac 帮助文档](https://github.com/GeorgeXiong24/STM-app/blob/main/Mac_helper.md)。
